Convert Griffeye HTML reports to a non-standard sized PDF document
- multiple columns from the HTML report can be printed and not limited to page size. 

tested on python version 3.14.7

to run on a fresh online system:
1) Install pip install playwright

Can be run on an offline system as the executable package contains all the modules necessary.

USAGE syntax - run script from cmd line: **python griffeye_to_pdf.py {path to html file} {path to output file}**
